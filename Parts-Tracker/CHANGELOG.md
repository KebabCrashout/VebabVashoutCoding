# Changelog

Each version is published on the GitHub Releases page with three downloads:

- **Parts-Tracker-Updater-x.y.z.exe**: updates an existing install and keeps your parts.
- **Parts Tracker Setup x.y.z.exe**: for a first install.
- **Parts-Tracker-x.y.z-portable.exe**: no install needed.

## 1.1.0

- **Several cars.** A new **Garage** tab lets you keep more than one car, each with its
  own parts, links, alternatives and Price Tracker totals. Switch cars from the dropdown
  in the top bar. Your existing parts move into your first car automatically, and a
  backup of the old file is kept.
- Each car has its own vehicle description, which the AI searches use to check a part
  fits. AI searches stay off for a car until it has one.
- Once a part is **Ordered, Received or Part Fitted**, its alternatives are hidden.
  Set it back to Not purchased and they return.
- "Use this part instead" now asks in a themed in-app box instead of a Windows dialog.
- Popups can be dragged by their title bar, and open centred again next time.
- Settings shows the app version.
- New **Updater** download for updating an existing install in one step.
